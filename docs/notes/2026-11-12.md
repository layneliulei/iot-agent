# 2026-11-12 · S2 Day 1 工具超时与错误回灌

## 卡在哪
- 异步节点不能用同步入口驱动：`agent.invoke()` 抛
  `TypeError: No synchronous function provided to "tool_node"`。
- `tool_call("args")` 圆括号 → `TypeError: 'dict' object is not callable`，
  被 `except Exception` 兜成「执行失败」，工具实际未执行。

## 为什么
- `langgraph/_internal/_runnable.py`：`coerce_to_runnable()` 对 async 可调用返回
  `RunnableCallable(None, afunc)`（sync 入口为 None），`RunnableCallable.invoke()`
  见 `self.func is None` 即抛 TypeError。同步 `def` 则被包成
  `RunnableCallable(fn, partial(run_in_executor, None, fn))`，自带 afunc。
  → 同步节点两用；异步节点只能 `ainvoke` / `astream`。
- 兜底把编程错误和业务异常一视同仁，反而掩盖了真实 bug。

## 怎么解
- 入口改异步：`asyncio.run(main())` + `await agent.ainvoke(...)`，`get_state` 保持同步。
- 修正括号；`ToolMessage` 保留异常类名；后续加 `logger.exception` 让兜底不无声。

- `run_tool_safely()`：`asyncio.timeout` + 超时/异常 → `ToolMessage` 回灌。
