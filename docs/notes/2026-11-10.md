## 两个环境坑（面试可讲）
1. **`python scripts/xxx.py` 的 `sys.path` 是脚本所在目录，不是项目根**
   → `from app.main import ...` 报 `ModuleNotFoundError`。`python -m pytest` 能用，是因为 `-m` 把 cwd 加了进去。
   修法：脚本里加 `sys.path.insert(0, str(Path(__file__).resolve().parents[1]))`。
2. **Docker build 的两跳网络**
   - Docker Desktop 配了 `static system HTTPS proxy http://127.0.0.1:7897` 而该进程未运行 → `load metadata` 阶段 `actively refused`（0.0s 就挂）
   - 代理起来后仍失败：`registry-1.docker.io` 通了（拿到 401），但 `auth.docker.io` 直连 `timeout` —— 换 token 那一跳没走代理
   - 最终：`No proxy` + `registry-mirrors`（国内源）+ pip 清华源 解决

## 一个观察
build 0.9s 完成、5 层全 `CACHED`：`COPY requirements.txt .` 单独一层且放在 `COPY . .` 之前，依赖没变时最贵那层不会失效 —— 这就是两条 `COPY` 顺序不能颠倒的原因。
